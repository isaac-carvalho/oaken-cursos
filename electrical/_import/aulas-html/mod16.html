Desenvolvimento Técnico

3.1. O que é um CLP?

Um CLP (Controlador Lógico Programável) – ou PLC (Programmable Logic Controller) em inglês – é um computador industrial especializado, utilizado para automatizar processos industriais (ex: controlo de bombas, motores, esteiras, máquinas-ferramenta). É programado para executar uma sequência de operações com base em entradas (sensores, botões) e gerar saídas (contactores, VFDs, sinalização).

Desenvolvimento Técnico

3.2. Evolução dos Sistemas de Controlo

Sistemas com relés: Controlo por contactores e relés. Utilizava muitos fios e era difícil de modificar. Comum antes dos anos 1970.

CLPs (anos 1970-1980): Substituíram os relés, permitindo programação flexível.

Sistemas de automação modernos: CLPs com comunicação em rede (Profibus, Modbus, Ethernet), integração com SCADA (Supervisory Control and Data Acquisition) e IIoT (Industrial Internet of Things).

Desenvolvimento Técnico

3.3. Principais Marcas de CLPs em Angola

Siemens: Simatic S7-1200, S7-1500 (muito usados na indústria angolana).

Schneider Electric: Modicon M241, M251.

Allen-Bradley (Rockwell): ControlLogix, CompactLogix.

WEG: CLP Weg – usado em aplicações específicas.

Mitsubishi: FX, Q-Series.

Omron: CP1H, CJ2.

Desenvolvimento Técnico

3.4. Vantagens do CLP

Flexibilidade: Pode ser reprogramado para novas funções sem alterar a fiação.

Fiabilidade: Componentes sólidos, sem contactos mecânicos (redução de avarias).

Facilidade de diagnóstico: O CLP pode indicar a origem de uma avaria.

Comunicação: Pode comunicar com outros CLPs, computadores e sistemas de supervisão.

Compacto: Ocupa menos espaço que um painel de relés.

Funcionalidades avançadas: Temporizadores, contadores, PID, matemática.

Desenvolvimento Técnico

3.5. Aplicações em Angola

Bombagem: Controlo de bombas em sistemas de abastecimento de água.

Ventilação: Controlo de ventiladores em fábricas e sistemas de climatização.

Processamento: Esteiras, misturadores, empacotadores (fábricas de alimentos, bebidas, pescado).

Petróleo e Gás: Controlo de processos em plataformas e refinarias (Soyo, Cabinda).

Mineração: Controlo de britadores, esteiras (Catoca, Lucapa).

Desenvolvimento Técnico

3.6. Estrutura Básica de um CLP

Um CLP é composto por:

CPU (Unidade Central de Processamento): Executa o programa e gerencia as operações.

Módulos de Entrada: Recebem sinais de sensores (botões, chaves, sensores de pressão).

Módulos de Saída: Enviam sinais para actuadores (contactores, VFDs, lâmpadas).

Barramento (Backplane): Comunicação entre CPU e módulos.

Fonte de Alimentação: Fornece energia (24V CC, 110/220V CA).

Interface de Programação: Para programar o CLP (software).

Desenvolvimento Técnico

3.1. Arquitectura Modular vs. Compacta

CLP compacto: CPU, entradas e saídas num único bloco. Ex: Siemens S7-1200, Schneider M241. Ideal para aplicações pequenas.

CLP modular: CPU, entradas, saídas e outros módulos separados, montados num barramento. Ex: Siemens S7-1500, Allen-Bradley ControlLogix. Ideal para aplicações grandes e complexas.

Desenvolvimento Técnico

3.2. CPU (Unidade Central de Processamento)

A CPU é o "cérebro" do CLP. Contém:

Microprocessador: Executa o programa.

Memória: Programa (ROM) e dados (RAM).

Portas de comunicação: Para programação e comunicação (Ethernet, Profibus, Modbus).

Indicadores LED: Estado (RUN, STOP, erro).

Desenvolvimento Técnico

3.3. Módulos de Entrada

Os módulos de entrada recebem sinais do campo (sensores, botões, chaves). Existem dois tipos principais:

Entradas digitais (DI): Sinais ON/OFF (0 ou 1, 24V DC ou 220V AC). Ex: botão, chave fim de curso.

Entradas analógicas (AI): Sinais analógicos (4-20mA, 0-10V). Ex: sensor de pressão, temperatura.

Desenvolvimento Técnico

3.4. Módulos de Saída

Os módulos de saída enviam sinais para actuadores (contactores, VFDs, lâmpadas). Existem dois tipos:

Saídas digitais (DO): Sinais ON/OFF (24V DC ou 220V AC). Ex: contactor (liga/desliga).

Saídas analógicas (AO): Sinais analógicos (4-20mA, 0-10V). Ex: controlo de VFD (velocidade).

Desenvolvimento Técnico

3.5. Barramento (Backplane)

O barramento é um sistema de comunicação que liga a CPU aos módulos de E/S. Pode ser:

Físico: Trilho onde os módulos são encaixados (ex: Siemens S7-1500).

Integrado: No CLP compacto (ex: S7-1200).

Desenvolvimento Técnico

3.6. Ciclo de Scan

O CLP executa um ciclo repetitivo (scan) com três etapas:

Leitura das entradas (Input Scan): Lê o estado das entradas.

Execução do programa (Program Scan): Executa o programa (ex: Ladder) com base nos valores lidos.

Actualização das saídas (Output Scan): Actualiza as saídas com os resultados do programa.

Desenvolvimento Técnico

3.4. Escalonamento (Scaling)

O valor digital (ex: 0-27648 para 4-20mA) deve ser convertido em valor de engenharia.

Exemplo: Sensor de pressão 4-20mA (0-10 bar).

4mA → 0 bar.

20mA → 10 bar.

12mA → 5 bar.

Fórmula:
Valor_eng = (Valor_digital - 0) * (Eng_max - Eng_min) / (Dig_max - Dig_min) + Eng_min

Desenvolvimento Técnico

3.1. Estrutura do Ladder

O Ladder (diagrama de contactos) é uma linguagem de programação gráfica que se assemelha a um circuito eléctrico com relés. É a mais comum em CLPs.

Linhas (Rungs): Cada linha é uma condição que leva a uma saída.

Barra esquerda: Fonte de alimentação (fase).

Barra direita: Neutro.

Desenvolvimento Técnico

3.2. Símbolos Básicos

Contacto NA (Normalmente Aberto): | | (fecha se a condição for verdadeira).

Contacto NF (Normalmente Fechado): |/| (abre se a condição for verdadeira).

Bobina: --( )-- (accionada se a condição for verdadeira).

Selo: Contacto NA em paralelo com a bobina.

Temporizador: --[ TON ]-- (atraso na ligação).

Contador: --[ CTU ]-- (contagem ascendente).

Desenvolvimento Técnico

3.1. Temporizadores

TON (Timer On-Delay): Atraso na ligação. A saída só é activada após um tempo determinado.

TOF (Timer Off-Delay): Atraso na desligação. A saída permanece activa após o sinal de entrada ser removido.

Desenvolvimento Técnico

3.2. Contadores

CTU (Counter Up): Contagem ascendente.

CTD (Counter Down): Contagem descendente.

Reset (R): Para resetar o contador.

Desenvolvimento Técnico

3.3. Comparadores

> (Maior que): Compara dois valores.

< (Menor que): Compara dois valores.

= (Igual a): Compara dois valores.
